## Recruiter Dashboard Functions

The recruiter dashboard provides access to:

1. Company Profile
2. Create Job Posting
3. Create Internship Posting
4. Manage Job Postings
5. Manage Internship Postings
6. View Applicants
7. Shortlist or Reject Applicants
8. Manage Applicant Status
9. Schedule Interviews
10. Logout
